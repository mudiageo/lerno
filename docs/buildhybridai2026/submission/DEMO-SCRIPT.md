# Demo script (≤3 minutes, public YouTube)

The entrant records and uploads this. Keep it under three minutes.

1. **0:00–0:20** — "This is Lerno. Students already use it for notes, quizzes and past questions. The problem: AI help usually stops working offline, and sensitive notes get sent to the cloud."
2. **0:20–0:40** — Open `/hybrid`. Show the capability badge and per-answer source badges. Press **Prepare model** and explain that Chrome's on-device model is now ready.
3. **0:40–1:10** — Paste notes into Offline Revision Pack, generate flashcards, show the `ON_DEVICE` badge. Turn off the network with the page still loaded and generate another pack. Show the queued state and sync after reconnect.
4. **1:10–1:35** — Private Pass: paste a note containing a name and matric number. Show the masked output and "kept on device" count.
5. **1:35–1:55** — Instant + Enhanced: show the fast answer badge, then the deeper `IN_CLOUD` answer. Explain Private Pass ran first.
6. **1:55–2:20** — Curriculum Bootstrap: upload a short prospectus PDF or paste a Drive link. Show structured courses, private-pass summary, editable preview, then confirm.
7. **2:20–2:40** — Snap-and-Mark if built: photograph a past question and answer, show on-device marking and any cloud escalation.
8. **2:40–2:55** — Show the data-saved counter and the public repo/licence. End with the demo URL and a one-line reminder that all inference is Firebase AI Logic.

Do not show `.env`, debug tokens, console secrets, private emails, or student PII.
